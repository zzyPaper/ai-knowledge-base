# stock-analyzer 调用说明

板块 ETF 轮动量化工程。由两部分组成：

- **`src/` 引擎 + 每日报告**：原 stock-analyzer，工程化 5 层流水线（regime→timing→signals→risk→portfolio）。
- **`etf_rotation/` 子包**：由 etf-rotation-strategy 合并进来（并排合并，2026-07-15 提交 `a0a92ac`），提供机制迭代系统、券商对接、可视化等。

> ⚠️ **所有命令都必须在 `stock-analyzer/` 目录下运行**（etf_rotation 使用相对导入，需作为子包被识别）。

---

## 一、每日股票报告（原引擎）

```bash
cd stock-analyzer
python3 scripts/run_daily_v2.py          # 实时模式，生成当日 14:40 操作建议
python3 scripts/run_daily_v2.py --date 2026-05-22   # 历史回测某天
python3 scripts/run_daily_v2.py --brief              # 简短输出
```

报告输出到 `data/results/<日期>_v2_report.md`。

---

## 二、etf_rotation 子包（合并而来）

### 1. 机制迭代系统（核心）

"不调参、加机制"——每轮回测过去一年（2 个月一个波段），分析不足并新增一个机制，共 30 轮。已内置 10 个机制：

`trend_filter`(趋势过滤) · `momentum_boost`(动量增强) · `stop_loss`(止损) · `profit_lock`(利润锁定) · `bear_defense`(熊市防御) · `dca_plus`(智能定投) · `grid_add`(网格加仓) · `volatility_stop`(波动率止损) · `etf_rotation`(ETF轮动) · `macro_timing`(宏观择时)

```bash
cd stock-analyzer
python3 -m etf_rotation.strategy_loop 30      # 跑 30 轮机制迭代
python3 -m etf_rotation.strategy_loop 10      # 指定轮数
```

### 2. 每日交易工作流

```bash
cd stock-analyzer
python3 -m etf_rotation.daily_run            # 14:40 生成信号，15:00 前执行
python3 -m etf_rotation.daily_run --confirm   # 收盘后确认成交
```

### 3. 模块地图

| 路径 | 作用 |
|------|------|
| `etf_rotation/strategy_loop.py` | 30 轮机制迭代系统 + `MechanismRegistry`（10 机制注册表） |
| `etf_rotation/strategy/builtin.py` | 经典策略：DCA / 均线 / 股债平衡 / 动量 / 网格 |
| `etf_rotation/strategy/base.py` | 策略基类与工具（`Account`/`Signal` 封装） |
| `etf_rotation/backtest/engine.py` | 回测引擎 `BacktestEngine` + `Signal` |
| `etf_rotation/backtest/account.py` | `Account` / `Position` / 赎回费计算 |
| `etf_rotation/trading/broker.py` | 券商接口抽象（`backtest`/`paper`/`live` 三模式） |
| `etf_rotation/trading/scheduler.py` | 尾盘定时交易调度 |
| `etf_rotation/report/dashboard.py` | 可视化面板（需 `matplotlib`，已安装） |
| `etf_rotation/data/fetcher.py` | 数据获取（akshare） |
| `etf_rotation/utils/` | 配置(`config.py`) + 交易日历(`time_utils.py`) |
| `etf_rotation/examples/custom_strategy.py` | 自定义策略示例 |

### 4. 自定义策略

参考 `etf_rotation/examples/custom_strategy.py`，实现 `def my_strategy(date, account, nav_data, fund_universe) -> List[Signal]`，即可接入回测/调度。
