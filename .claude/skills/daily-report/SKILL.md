# 每日双引擎量化报告

每天下午 2:45 运行两个独立的量化引擎，汇总结果给出一致的买卖建议，赶在 3 点收盘前执行。

## 参数预设

| 参数 | 值 |
|------|-----|
| 总资金 | 5000 元 |
| 初始仓位 | 0（每天从零开始计算目标仓位） |
| 基准指数 | 沪深300 |

## 两个引擎

| 引擎 | 路径 | 策略 | 输出 |
|------|------|------|------|
| **stock-analyzer** | `stock-analyzer/` | 专业行业轮动（5层：RegimeDetector → MarketTiming → SignalPipeline → RiskManager → PortfolioBuilder） | 市场状态 + 入场/离场判断 + 目标持仓 |
| **quant-aio** | `quant-aio/` | V2 七因子策略（趋势+动量+量能+资金+情绪+景气度+估值） | 板块排名 + 综合评分 + 因子明细 + 买卖信号 |

## 执行步骤

### Step 1: 并行运行两个引擎

```bash
# 引擎1: stock-analyzer 专业行业轮动
cd stock-analyzer && python3 scripts/run_daily_v2.py --brief 2>&1

# 引擎2: quant-aio V2七因子策略
cd quant-aio && python3 main.py daily --strategy v2 --top-n 5 2>&1
```

### Step 2: 解析输出

从两个引擎的输出中提取关键信息：

**stock-analyzer 提取项：**
- 市场状态（regime）和仓位上限
- 20日/10日/60日动量
- 入场/离场条件是否满足
- 建议买入的板块、ETF代码、金额
- 沪深300实时涨跌

**quant-aio 提取项：**
- 市场状态（趋势市/震荡市）
- 板块排名（综合分、信号、仓位百分比）
- 各因子明细
- 建议买入板块列表

### Step 3: 汇总报告

按以下格式输出统一报告：

```

══════════════════════════════════════════════════
```

### Step 4: 保存报告

```bash
cat > stock-analyzer/data/results/$(date +%Y-%m-%d)_merged_report.md << 'REPORT_EOF'
<报告内容>
REPORT_EOF
```

## 合并规则

1. **共识板块**（两引擎都推荐）→ 优先级最高，可以直接买入
2. **仅引擎1推荐**（轮动策略看好，但七因子策略未选入 top 5）→ 次优先级，检查因子明细是否有明显弱点
3. **仅引擎2推荐**（七因子看好，但轮动策略未选中）→ 检查是否因 ETF 映射缺失或轮动策略的拥挤度过滤排除
4. **分歧较大时**（共识度 < 40%）→ 建议降低仓位，只买共识板块

## 注意事项

- 两个引擎都是**从零开始计算**，不依赖历史持仓
- 引擎1 有入场/离场条件判断，如果市场不满足入场条件，会建议空仓
- 引擎2 始终输出板块排名，不判断市场整体入场时机
- 如果引擎1 建议空仓但引擎2 推荐买入，以引擎1 的市场择时判断为准（保守原则）
- 盘中实时数据来自腾讯 API，可能有 15 秒延迟
