我需要你搭建一个实时分析股票并给出购买策略的软件程序。初版可以用python进行快速开发，后续可以把某些密集流程下放到c++。
现在需要你先进行前期的调研，调研市面上常见的分析购买量化策略。然后你还需要数据。可以参考下面这个别人的总结，自己构建这些数据源。
然后你需要基于策略和数据，搭建一个分析买卖的程序，每天下午2点：30开始运行。跟踪A股的热门板块，给出操作建议。
数据就是分析当天热门板块（成交量最大的那几个）的开盘价、收盘（2:30接近收盘）价，最高价、最低价、涨跌归因，以及最近30d的日k。至于实际策略需要你查一下，实现一下。
最后，这个软件需要你进行自循环测试迭代，可以搭建一个测试软件或测试用例，随便你。需要让他基于a股的历史数据进行模拟买卖，可以买卖2个月，看收益率。这个反复测试的目标是提升收益率，如果收益率未达标（比如超过同期A500 10点收益率），则分析调整买卖策略，基于同样的数据重新进行测试。测试完2个月，达标了，测试后2个月。总之反复测试最近一年的数据。

另外，我要声明，自循环只是一个训练过程，这个过程有你参与，但是训练完以后，它就是一个成熟的程序了，我启动它得到结果不需要你参与

测试者通过实测 7 个开源数据源，筛选出 5 个可用于搭建大 A 稳定数据源的工具。
数据源筛选结果：测试者实测通达讯、腾讯财经、AKshare、iwencai、同花顺热点、tushare、Ashare 共 7 个数据源，因 tushare 收费且免费数据少、Ashare 项目停更接口失效，最终保留前 5 个。
行情数据搭配：通达讯可提供实时价格、5 档盘口、全周期 K 线及逐笔成交数据，无需 API 即可连接；腾讯财经为公开 API，可提供 PE、PB、市值、换手率等计算类数据，二者互补可覆盖全面行情数据。
特色功能数据源：同花顺热点可提供当日强势股题材归因；iwencai 支持语义跨主题检索，需登录获取 API key 才能使用。
研报与基础数据：AKshare 可调取东财 PDF 版研报、机构一致预期数据；基础数据优先用通达讯调取财报、EPS、公司概况等，部分缺失数据可由 AKshare 补充。
公告数据获取：公告数据可通过 AKshare 封装的巨潮接口，或通达讯的公告摘要信息获取。
